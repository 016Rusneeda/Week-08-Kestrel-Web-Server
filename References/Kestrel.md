## เว็บเซิร์ฟเวอร์ Kestrel ใน ASP.NET Core

โดยTom Dykstra, Chris Ross, และ Stephen Halter

Kestrel เป็นเว็บเซิร์ฟเวอร์แบบข้ามแพลตฟอร์มสำหรับ ASP.NET Core 
Kestrel เป็นเซิร์ฟเวอร์ที่แนะนำสำหรับ ASP.NET Core และถูกกำหนดค่าไว้เป็นค่าเริ่มต้นในเทมเพลตโปรเจ็กต์ ASP.NET Core

### คุณสมบัติของ Kestrel ได้แก่


| ประเด็น                                             | รายละเอียด                                                                                                                                                                                         |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **รองรับหลายแพลตฟอร์ม**                             | Kestrel เป็นเว็บเซิร์ฟเวอร์ที่ใช้งานได้บนหลายแพลตฟอร์ม ได้แก่ Windows, Linux และ macOS                                                                                                             |
| **ประสิทธิภาพสูง**                                  | Kestrel ได้รับการปรับแต่งให้สามารถจัดการกับการเชื่อมต่อพร้อมกันจำนวนมากได้อย่างมีประสิทธิภาพ                                                                                                       |
| **น้ำหนักเบา**                                      | ออกแบบมาเพื่อใช้งานในสภาพแวดล้อมที่มีทรัพยากรจำกัด เช่น คอนเทนเนอร์และอุปกรณ์ Edge                                                                                                                 |
| **ระบบรักษาความปลอดภัยได้รับการเสริมความแข็งแกร่ง** | Kestrel รองรับ HTTPS และได้รับการเสริมความแข็งแกร่งเพื่อป้องกันช่องโหว่ของเว็บเซิร์ฟเวอร์                                                                                                          |
| **การรองรับโปรโตคอลที่หลากหลาย**                    | Kestrel รองรับโปรโตคอลเว็บทั่วไป ได้แก่ <br>- HTTP/1.1, HTTP/2 และ HTTP/3 (ตั้งแต่ .NET 11 เป็นต้นไป HTTP/3 ใช้การประมวลผลคำขอเบื้องต้นเพื่อลดความหน่วงเวลาในการส่งคำขอครั้งแรก)<br>- เว็บซ็อกเก็ต |
| **การผสานรวมกับ ASP.NET Core**                      | ผสาน รวมอย่างราบรื่นกับส่วนประกอบอื่นๆ ของ ASP.NET Core เช่น มิดเดิลแวร์ไปป์ไลน์ การฉีดการพึ่งพา และระบบการกำหนดค่า                                                                                |
| **เวิร์กโหลดที่ยืดหยุ่น**                           | Kestrel รองรับเวิร์กโหลดได้หลากหลาย ได้แก่<br>- เฟรมเวิร์กแอปพลิเคชัน ASP.NET เช่น Minimal APIs, MVC, Razor Pages, SignalR, Blazor และ gRPC<br>- การสร้างรีเวิร์สพร็อกซีด้วยYARP                   |
| **ความสามารถในการขยาย**                             | ปรับแต่ง Kestrel ผ่านการกำหนดค่า มิดเดิลแวร์ และการขนส่งแบบกำหนดเอง                                                                                                                                |
| **การวิเคราะห์ประสิทธิภาพ**                         | Kestrel มีคุณสมบัติการวิเคราะห์ประสิทธิภาพในตัว เช่น การบันทึกข้อมูลและการวัดค่าต่างๆ                                                                                                              |
| **การจัดการหน่วยความจำ**                            |  Kestrel มีคุณสมบัติสำหรับการจัดการหน่วยความจำอย่างมีประสิทธิภาพ                                                                                                                                   |

>[!info]
macOS รองรับการพัฒนา ASP.NET Core การทดสอบ การรวมระบบอย่างต่อเนื่อง (CI) และบริการภายในเครื่องโดยไม่ต้องเข้าถึงจากภายนอก แต่ไม่รองรับงานเซิร์ฟเวอร์สำหรับการใช้งานจริง ไม่มี macOS เวอร์ชันเซิร์ฟเวอร์ และApple ได้ยุติการสนับสนุน macOS Server แล้วสำหรับการโฮสต์ในสภาพแวดล้อมการใช้งานจริง ควรใช้ระบบปฏิบัติการเซิร์ฟเวอร์ Windows หรือ Linux แทน

### ตัวอย่าง

```C#
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

app.MapGet("/", () => "Hello World!");

app.Run();
```

สำหรับข้อมูลเพิ่มเติมเกี่ยวกับการกำหนดค่าWebApplicationและ การใช้งาน โปรดWebApplicationBuilderดูที่ คู่มืออ้างอิงฉบับย่อของ Minimal APIs
